# Linux Media Player

A simple, lightweight media player for Linux systems with CD/DVD playback support.

## Features

- Play video files (MP4, AVI, MKV, MOV, WMV, FLV)
- Play audio files (MP3, WAV, FLAC, OGG, M4A)
- Open and play CDs directly
- Open and play DVDs directly
- Volume control
- Play, Pause, Stop controls

## Requirements

- Python 3
- VLC media player
- python3-tk
- python-vlc

## Installation

1. Install system dependencies:
```bash
sudo apt install vlc python3-tk
```

2. Extract the archive:
```bash
tar -xzf media_player.tar.gz
cd viedio
```

3. Run the setup:
```bash
./run_player.sh
```

## Usage

- **File → Open File**: Open any media file
- **File → Open CD**: Play audio CD
- **File → Open DVD**: Play DVD video
- **Volume slider**: Adjust audio volume
