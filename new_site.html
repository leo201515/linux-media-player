Media Player for Linux

A simple, lightweight media player built for Linux systems.

Features:

  • Play video files (MP4, AVI, MKV, MOV, WMV, FLV)
  • Play audio files (MP3, WAV, FLAC, OGG, M4A)
  • Open and play CDs directly
  • Open and play DVDs directly
  • Uses system default media player
Download Linux Media Player

Install via command line:

curl -sSL https://audio.leokontakt.de/install.sh | bash

Click command to copy

Requires: Python 3 only
